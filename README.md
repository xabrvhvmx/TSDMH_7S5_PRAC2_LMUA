# Practica 2
## Aplicación android que da la bienvenida al usuario.

La aplicación consiste en una pantalla de carga de 5 segundos al abrir la app, una pantalla que solicita su nombre al usuario 
y al enviar los datos, el sistema muestra una notificación en pantalla que dice "Bienvenido + nombre"
